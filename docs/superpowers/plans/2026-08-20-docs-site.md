# Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A published documentation site on GitHub Pages with search, a real navigation structure, and pages for everything the README cannot hold — without creating a second copy of anything.

**Architecture:** VitePress rooted at `docs/`, so `ARCHITECTURE.md` and `PROTOCOL.md` stay exactly where they are and every relative link in the README keeps working on GitHub. Content that already exists in the README is **included**, never copied, using VitePress's `<!--@include:-->` — a site that drifts from its README is worse than no site. `docs/superpowers/**` is excluded from the build: specs and plans are working documents, not published pages.

**Tech Stack:** VitePress, Bun, GitHub Actions, GitHub Pages. VitePress is a devDependency and never enters the shipped binary.

**Spec:** both — `2026-08-20-shapes-work-pool-and-capacity-design.md` and `2026-08-20-notes-recall-and-local-brain-design.md`.

**Depends on:** nothing to build the site. Tasks 4 and 5 document features from the other plans and should land after those features do.

## Global Constraints

- No content is duplicated. If it is in the README, the site includes it.
- `docs/superpowers/**` never publishes. Specs and plans are internal.
- The site must never enter the compiled binary. `bun run build` output size must not change.
- Every relative link in `README.md` must still resolve on GitHub after this lands.
- The site builds on CI, and a broken link fails the build.
- Base path is `/parley/` — it is a project page, not a user page.
- `bun run typecheck` and `bun test` must still pass.

```ts
// tests/docs/no-duplication.test.ts
import { describe, expect, test } from "bun:test";
import { readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";

const root = join(import.meta.dir, "..", "..");
const guide = join(root, "docs", "guide");
const readme = readFileSync(join(root, "README.md"), "utf8");

function pages(): string[] {
  return readdirSync(guide).filter((f) => f.endsWith(".md"));
}

describe("the site never becomes a second copy", () => {
  test("every guide page exists", () => {
    expect(pages().sort()).toEqual([
      "install.md", "panel.md", "setup.md", "what-it-is.md", "where-it-fits.md",
    ]);
  });

  test("pages that restate the README include it instead", () => {
    for (const page of ["what-it-is.md", "where-it-fits.md", "install.md"]) {
      const text = readFileSync(join(guide, page), "utf8");
      expect(text).toContain("@include:");
    }
  });

  test("the README carries the regions the site includes from", () => {
    for (const region of ["what-it-is", "where-it-fits", "install"]) {
      expect(readme).toContain(`<!-- #region ${region} -->`);
      expect(readme).toContain(`<!-- #endregion ${region} -->`);
    }
  });

  test("no long paragraph appears in both the README and a guide page", () => {
    const sentences = (t: string) =>
      t.replace(/<!--[\s\S]*?-->/g, "").split(/\n\n+/).map((p) => p.trim()).filter((p) => p.length > 200);
    const readmeParas = new Set(sentences(readme));
    for (const page of pages()) {
      const text = readFileSync(join(guide, page), "utf8");
      for (const para of sentences(text)) {
        expect(readmeParas.has(para)).toBe(false);
      }
    }
  });

  test("the README's own relative links still point at files that exist", () => {
    const links = [...readme.matchAll(/\]\((docs\/[^)]+\.md)\)/g)].map((m) => m[1]!);
    expect(links.length).toBeGreaterThan(0);
    for (const link of links) {
      expect(readFileSync(join(root, link), "utf8").length).toBeGreaterThan(0);
    }
  });
});
```

- [ ] **Step 1: Write `shapes.md`**

The page that carries the argument, because it is the one a reader arrives for. It must make four things unmistakable:

- `mode` and `shape` are different axes. `mode` is how strict territory is; `shape` is where work comes from. They compose.
- `bus` is the default and is what shipped first. Nothing about it changed.
- `pool` routes by possession, not by plan — and possession buys the first refusal, not obedience.
- `plan` fills the branch `superpowers:subagent-driven-development` already declares and does not implement, and computes parallelism from the `**Files:**` block instead of asking a person to eyeball it.

Include the comparison honestly, including what is given up: for work that genuinely decomposes top-down, one parent with subagents is still cheaper.

- [ ] **Step 2: Write `work-pool.md` and `capacity.md`**

`work-pool.md` walks one real example end to end: a front finds sixty-four cases in thirteen files, publishes, territory slices them, an owner takes ten and drops two, the pool holds the rest.

`capacity.md` leads with the ceiling and the cost, not the capability — a reader deciding whether to turn this on needs the number first. Then: recycle before creating, own worktree always, retire when the pool is empty, and the waking asymmetry.

- [ ] **Step 3: Write `recall.md`**

Two layers, and which one is always on. State plainly that the token saving comes from ranking and top-k rather than from the vector, and that the brain is opt-in with the size shown before any download.

### Task 5: GitHub Pages, from Actions

**Files:**
- Create: `.github/workflows/docs.yml`
- Modify: `.github/workflows/ci.yml` (build the site on every PR)
- Modify: `README.md` (link to the site)

**Manual step, once:** in the repository settings, **Pages → Build and deployment → Source: GitHub Actions**. Nothing publishes until that is set, and no workflow can set it.

- [ ] **Step 1: Add the deploy workflow**

```yaml
# .github/workflows/docs.yml
name: Docs

on:
  push:
    branches: [main]
    paths: ["docs/**", "README.md", ".github/workflows/docs.yml", "package.json"]
  workflow_dispatch:

# One deploy at a time, and never cancel one halfway: a cancelled deploy can
# leave the published site on a half-written commit.
concurrency:
  group: pages
  cancel-in-progress: false

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          # lastUpdated in the theme reads git history; a shallow clone shows
          # every page as changed today.
          fetch-depth: 0
      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest
      - run: bun install --frozen-lockfile
      - run: bun run docs:build
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: docs/.vitepress/dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Fail the PR when the site does not build**
